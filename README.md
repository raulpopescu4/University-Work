# University Work Repository

Welcome to my University Work Repository! This repository contains a collection of projects and assignments completed during my university studies. Below, you'll find a summary of the key projects included in this repository.

## Projects

### Mobile Applications

This project is an Android mobile application developed as part of the coursework. It focuses on implementing some simple CRUD functionalities using *Flutter*.

### ufc-app

The **ufc-app** is part of the Systems for Design and Implementation course. It is a simple web application developed using *Node.js* for the server-side and *React* for the client-side. It has two entities with a one-to-many relationship and CRUD functionalities for them.

### Object-Oriented Programming (OOP)

Projects under this section demonstrate the application of OOP principles using *C++* in various assignments and exercises including tests.


### Design Patterns

This section covers the implementation of various design patterns studied during the course into a simple restaurant application type project with a command-line interface, using *Java*.


### Robotic Process Automation (RPA)

The RPA section includes assignments and a project where automation of repetitive tasks is achieved using *UiPath*.
